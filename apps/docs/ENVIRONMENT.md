# Local Development & Environment Setup
Follow these steps to configure and run Rin locally.
## Prerequisites
- **Node.js**: >= 18.0.0
- **npm**: >= 10.0.0
- **Redis instance**: Local Redis or [Upstash Redis](https://upstash.com)
- **PostgreSQL**: Local PostgreSQL or [Supabase](https://supabase.com) / [Neon](https://neon.tech)
- **GitHub App**: Configured on GitHub Developer Settings with appropriate webhook permissions.
